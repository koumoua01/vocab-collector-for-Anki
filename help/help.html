Vocab Collector Help

Your guide to capturing words and saving them to Anki.

Prerequisites
  1. Anki Desktop must be installed and running.
  2. AnkiConnect add-on must be installed (Code: 2055492159).

Make sure to restart Anki after installing the add-on.

Features

  • Capture selected text from any webpage.
  • Auto-define words using free dictionary APIs or AI.
  • Smart Analysis detects word forms, synonyms, antonyms, and usage examples.
  • Customizable deck, model, and field mapping for Anki cards.
  • History keeps track of words you've recently added.

How to Use

Method 1: Quick Popover (Recommended)

  1. Double-click any word on a webpage (or select valid text).
  2. A popover will appear with definition and details.
  3. Review the information. You can edit any field.
  4. Click Save to send directly to Anki.

Note: You can disable the double-click trigger in Options > Appearance & Behavior if you prefer using only the Right Click menu.

Method 2: Right Click Context Menu

  1. Select text on any page.
  2. Right-click and choose Save vocab to Anki.
  3. The popover will appear.

Method 3: Toolbar Popup

  1. Click the extension icon in your browser toolbar.
  2. Click Add New Vocab.
  3. This will trigger the popover on the current page for the active selection.

Configuration

Access the Options page by clicking the "Options" button in the extension popup or right-clicking the extension icon.

Anki Connection

  • URL: Default is http://127.0.0.1:8765.
  • Deck: The name of the Anki deck to save cards to (e.g., "English").
  • Model: The note type to use (e.g., "Basic", "Vocab Card").

AI Definitions (Optional)

To use AI definitions (powered by OpenRouter):

  1. Get an API key from OpenRouter.ai.
  2. Enter the key in the Options page.
  3. Select Definition Source as AI in the popover or set it as default in Options.

Field Mapping

The extension can fill the following fields in your Anki note:

  • Word: The captured term.
  • Definitions: Meanings of the word.
  • Dictionary Example: Example sentence from the dictionary/AI.
  • Part of Speech: e.g., Noun, Verb.
  • Synonyms / Antonyms
  • Phonetic: Pronunciation guide (IPA).
  • Origin: Etymology.
  • Source Example: The sentence where you found the word.
  • Source: URL of the page.

Go to Options > Field Mapping to match these to your specific Anki note type names.

Troubleshooting

  • Connection Failed? Ensure Anki is open and AnkiConnect is installed. Check if the URL is correct.
  • No Popover? Refresh the page. The extension cannot run on some restricted browser pages (like the New Tab page or extension store).
  • AI Errors? Check your usage limits on OpenRouter and ensure you have selected a valid model.
